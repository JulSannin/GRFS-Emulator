# GRFS для Windows

В архиве `GRFS-Windows-x64.zip` — сервер и клиентский лаунчер для Windows x64.
Устанавливать Python на компьютеры игроков и сервера не нужно.

## Сервер

1. Распакуйте архив в отдельную папку с правом записи.
2. Запустите `GRFS-Server.exe` и дождитесь строки `ready:`.
3. Разрешите входящие подключения в брандмауэре: TCP 80, UDP 21030–21033.
4. Передайте игрокам IP компьютера с сервером. Для остановки нажмите Ctrl+C.

Настройки читаются из `grfs.ini` рядом с сервером; шаблон — `grfs.ini.example`.
Там же создаются `data/` с аккаунтами, друзьями, профилями и остальными
сохраняемыми данными, а также `logs/grfs.log`. Путь `data_dir` можно изменить.
Архив нужно распаковать целиком: папка `python/` содержит штатный подписанный
Python с python.org, а `app/` — сервер и обе таблицы из `app/schema/`.
Не переносите серверный `.exe` отдельно от этих папок. Профили, настройки
и журналы остаются рядом с серверным `.exe`.

Страница состояния: <http://127.0.0.1:8080/>. Порт 8080 для подключения игры
не требуется. Для доступа через интернет перенаправьте TCP 80 и UDP 21030–21033
на сервер; при NAT укажите в `advertise` адрес, доступный игрокам.

## Лаунчер игры

1. Запустите `GRFS-Client.exe` обычным двойным щелчком.
2. Введите IP сервера. На компьютере с сервером используйте `127.0.0.1`.
3. Дождитесь проверки конфигурации, UDP-сервисов и NAT.
4. Разрешите запрос Windows для настройки `hosts` и брандмауэра.
5. Подтвердите запуск игры. Если она не найдена в Steam, укажите её папку
   или перетащите игровой `.exe` в окно лаунчера.

Это консольный лаунчер: IP и ответы вводятся в его окне. Он направляет
`onlineconfigservice.ubi.com` на сервер, настраивает входящие UDP 2346–2347
для игры и при необходимости выбирает сетевой адрес для её запуска.
Повышение прав запрашивается для настройки Windows; игру запускает обычный
процесс лаунчера. Нужна установленная игра, доступная через ваш аккаунт Ubisoft.

Команды без запуска игры:

```powershell
.\GRFS-Client.exe --check 192.168.1.8
.\GRFS-Client.exe --off
```

`--check` только проверяет подключение. `--off` убирает добавленный лаунчером
блок из `hosts` и его правило брандмауэра. Настройки действуют до отключения.

## Сборка из исходников

На Windows нужны 64-битный Python 3.14 с Python Launcher и компилятор C#
из .NET Framework 4. Выполните `build_windows.bat` из корня репозитория.
Результат — два `.exe` и `dist/GRFS-Windows-x64.zip`.

Для подготовленного окружения:

```powershell
python tools/build_windows.py
```

Параметр `--server 192.168.1.8` задаёт предлагаемый лаунчером IP; по умолчанию
он спрашивает адрес. В архив не включаются локальные настройки, профили и логи.

Проверка готового архива: `python tools/smoke_windows.py`. Она запускает сервер
на свободных локальных портах, проверяет статистику, сессии, карты и клиентский
`--check`, затем перезапускает сервер и проверяет сохранённый профиль.
Параметр `--runtime-only` проверяет сервер через комплектный подписанный Python,
пропуская нативные лаунчеры, если их запуск ограничен политикой подписи Windows.

## Политика подписи Windows

Лаунчеры не имеют цифровой подписи. Windows с обязательной проверкой издателя
может заблокировать их запуск; для такой среды нужна подпись доверенным сертификатом.
Штатный Python из комплекта имеет собственную подпись Python Software Foundation.
Сервер можно запустить через него из папки распакованного архива в PowerShell:

```powershell
$env:GRFS_RUNTIME_DIR = $PWD.Path
.\python\python.exe -X utf8 -m grfs
```
